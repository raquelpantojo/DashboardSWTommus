Detailed Description

Casca fina: janela que hospeda o ScreenScanView. Substitui a antiga ScreenScanWindow (Window + XAML) — todo o conteúdo e a lógica agora vivem no UserControl ScreenScanView, que também pode ser embutido diretamente na MainWindow (aba 3D Visualization).

IMPORTANTE: remova do projeto os arquivos antigos ScreenScanWindow.xaml e ScreenScanWindow.xaml.cs antes de compilar, senão haverá conflito de classe duplicada.
